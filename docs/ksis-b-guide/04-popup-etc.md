## 4-1. 업무 팝업 [43번] — 먼저 범위 보고 · 허락받기

대상: 작성 · 상세 팝업(`.write-modal-overlay` / `.write-modal-box` + 안의 `.docform-*` · `.vform-*`). 그래프가 든 팝업(수주잔고 그래프 · `.obg-*` · `.graph-tab-shell` 등)은 높이 규칙이 달라 **목록만 보고하고 따로 묻습니다**.

바뀌는 점(B 메모): 크기를 화면 비율(50%×80~88%)에서 **고정 폭**으로, 둥근 ✕ 버튼 대신 **머리줄**, 한 줄 1항목에서 **한 줄 2항목 + 번호 붙은 절**, 오른쪽 아래 작은 버튼(9.3px) 대신 **아래 회색 띠 가운데 넓은 버튼**. 전체 화면 버튼은 **유지**.

**바깥 · 크기**
```css
.write-modal-overlay { background: var(--k-overlay); }          /* 뒤 화면 45% 어둡게 (지금과 같음) */
.write-modal-box {
    display: flex; flex-direction: column;
    width: 1100px;                       /* 대 1100 / 중 700 / 소 500 / 아주 작은 450 — 팝업마다 클래스로 고름 */
    max-width: calc(100vw - 20px);
    height: auto; min-width: 0; min-height: 0;   /* 지금의 50vw · 80vh · min 480×500 을 없앰 */
    border-radius: 16px;
    background: #FFFFFF;
    box-shadow: var(--k-pop-shadow);     /* 0 12px 40px rgba(0,0,0,.25) */
    overflow: hidden;
}
.write-modal-box.is-fullscreen { width: 100vw; max-width: none; height: 100vh; border-radius: 0; }
```
- 팝업마다 대 · 중 · 소 중 어느 폭을 쓸지 **표로 제안하고 확인받습니다**.

**머리줄** (새로 추가, 잡고 끌어 옮기기)
- 흰 바탕 + 왼쪽 주 색 막대 5px(#03C75A) + 굵은 제목 18px(왼쪽 정렬, 굵기 700, 자간 −0.3px, #1B1D1F) + 아래 줄 1px `var(--k-pop-line)` #DCEFE3. 안쪽 여백 14px 20px, 사이 8px.
- 지금 가운데 정렬 제목(`.docform-title` 18px 800)은 이 머리줄 제목으로 옮깁니다.
- 오른쪽 끝: [⛶ 전체 화면] (KSIS-B 만) · [✕ 닫기] — 각 30×30, 모서리 8px, 바탕 없음, 16px, #666666.
  ✕ 올림 = 바탕 #FFF0F0 · 글자 #E53E3E, ⛶ 올림 = 바탕 #E7F9EE · 글자 #03C75A. 지금의 둥근 떠 있는 버튼(`.write-modal-close`, `.write-modal-fullscreen-btn` 의 50% 모서리 · 그림자 · absolute)은 없앱니다.
- 머리줄을 잡고 끌면 팝업이 따라 움직입니다(커서 `move`, 글자 선택 안 됨). Esc 로 닫힘. 동작은 `ksis-modal.js` 참고(JS interop 으로 붙여도 됨).

**파일 업로드** (새 기능 — A · B 모두 없던 것)
- 값 칸 안에 "끌어다 놓는 칸" = [파일 선택] 버튼:
  점선 테두리 1.5px #D8DCE1, 모서리 10px, 최소 높이 64px, 바탕 #FAFBFC, 안쪽 10px 14px, 글자 13px #767676.
  가운데에 `파일을 여기로 끌어다 놓거나 [파일 선택]`, 아래 작은 글씨(11.5px #A6A6A6)로 올릴 수 있는 종류 · 최대 크기(예: `.xlsx · .xls · .pdf · .png · .jpg · 최대 20MB`).
- 칸 어디를 눌러도 파일 선택 창(Enter · Space 도). 올리면 테두리 #03C75A.
- 파일을 끌고 칸 위에 올라오면 테두리 실선 #03C75A + 바탕 #E7F9EE + 글자 #1F7A44. 여러 개 한 번에.
- **칸 밖(팝업 다른 곳 · 뒤 화면)에 놓으면 아무 일도 없어야 함**(브라우저가 파일을 열며 화면을 떠나지 않게 — `window` 의 `dragover` · `drop` 기본 동작 막기).
- 넣은 파일은 칸 아래 목록: 줄 높이 30px, 이름(길면 …) · 크기(KB/MB, 12px #767676) · ✕ 빼기(24×24, 올림 #FEE2E2/#E53E3E). 줄 사이 1px #DCEFE3. 같은 이름 · 같은 크기는 한 번만.
- 화면마다 정할 것: 확장자, 파일 하나 최대 크기(기본 20MB), 최대 개수, 한 개만 / 여러 개. 넘는 파일은 넣지 않고 알림 창(4-3)으로 어떤 파일이 왜 빠졌는지 알림.
- Blazor 팁: 지금 쓰는 `<InputFile>` 을 끌어다 놓는 칸 전체에 투명하게 덮으면(`.file-upload-input` 방식) 브라우저 기본 기능으로 끌어다 놓기가 됩니다. `InputFile` 스타일은 전역 `app.css` 에 있어야 한다는 지금 주석은 그대로 지킵니다.

## 4-3. 알림 · 확인 창 [44번] — 먼저 범위 보고 · 허락받기

- `[삭제] → [정말 삭제]` 두 번 누르기 화면은 확인 창 한 번으로 바꿀지 **묻습니다**.

## 확인 방법

1. 시연 프로그램 `/view/req-b/popup` · `/dialog` · `/text` 와 나란히 비교(1920×1080).
2. 팝업: 폭 1100(또는 정한 폭), 머리줄 왼쪽 초록 막대, 머리줄 끌어 옮기기, Esc 닫기, ⛶ 전체 화면, 첫 입력칸에 커서, 본문만 스크롤, 아래 회색 띠 가운데 150px 버튼.
